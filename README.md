# MAD Assignment 2

Flutter app with a splash animation, navigation (Navigator.push/pop + Drawer),
a ListView (List screen) and a GridView (About screen). Bonus: CustomScrollView + SliverAppBar.

## Run
1. Open this folder in Android Studio.
2. In the terminal run: `flutter create . --project-name mad_assignment --platforms=android`
3. Run `flutter pub get`, then press Run.
